# Capturas para las tarjetas de Trello

Capturas de las pantallas implementadas, con datos ficticios. Abre la carpeta
`capturas` para adjuntar las imágenes a Trello. También se entrega
`Capturas-Trello.zip` para trasladar todas juntas.

| Tarjeta | Capturas |
| --- | --- |
| Acceso y RUC | `HP-acceso-01` inicio de sesión con RUC/correo/contraseña; `HP-acceso-02` selección de sucursal; `HP-ruc-03` registro; `HP-ruc-04` alta de tenant; `HP-ruc-05` edición con RUC |
| HP4 DEV-CATALOG | `HP4-catalogo-01` tarifario, servicios y convenios; `HP4-catalogo-02` registro de servicio; `HP4-catalogo-03` registro de convenio |
| HP5 DEV-PACIENTE | `HP5-pacientes-01` directorio; `HP5-pacientes-02` filiación y autocompletado por DNI; `HP5-pacientes-03` antecedentes e historial con autor/fecha; `HP5-pacientes-04` nueva versión |
| HP6 DEV-HISTORIA-TXT | `HP6-historia-texto-01` ficha y estados; `HP6-historia-texto-02` consulta guardada; `HP6-historia-texto-03` móvil |
| HP7 DEV-HISTORIA-VOICE | `HP7-dictado-01` campo activo y texto agregado; `HP7-dictado-02` micrófono denegado con escritura manual; `HP7-dictado-03` navegador sin reconocimiento |

Las imágenes documentan la demostración visual. La validación real de Java y SQL
Server está descrita en el
[informe de entrega](../../docs/produccion/ENTREGA_TARJETAS_4_7_20261113.md).
La comprobación en Somee queda pendiente de su conexión exclusiva de Health Project.
